- 修复采集帧传递、窗口标题变化识别和异常图像处理，减少切换会话时的识别遗漏。
- 改进 OCR 消息衔接，保留重复消息及不同发言人的相同内容；无法识别会话名称时重新尝试识别。
- 修复 Windows OCR 图像尺寸处理及坐标换算，明确提示韩语识别组件缺失等问题。
- 修复采集进程退出后的状态恢复，并为长时间未收到有效画面提供操作提示。

## 下载与使用

下载 `jev-chat-windows-v0.3.2.zip`，完整解压后运行 `jev-chat-windows.exe`。请保留程序旁的 `_internal` 文件夹。

OpenAI 分析使用 `OPENAI_API_KEY`，其他分析服务使用 `JEV_API_KEY`。回复起草为可选功能，所有起草服务均使用独立的 `LLM_API_KEY`。回复填入后，由用户确认发送。
