## LM Studio 本地决策

- 新增“LM Studio 本地决策”分析来源，通过原生 `/v1/systemone` 接口完成意图、语气、紧张度评分及候选排序。
- 支持配置本地服务地址和模型标识；“获取模型”只显示决策模型，已加载时使用实际实例标识。
- 本地认证令牌为可选项，启用认证后使用 `LMSTUDIO_API_TOKEN`。云端分析和回复起草继续使用各自独立的密钥。
- 随包提供 `tools/lmstudio-d3-mini.defaults.json` 加载配置模板。

## 精简与修复

- 分析、起草和排序共用一次构建的聊天状态。评分明确以 `chat.reply_target` 为唯一对象，修复群聊中混入其他成员情绪的问题。
- 起草只提交一次请求，接受完整 JSON 字符串数组，按原文去重并保留标点；移除逐行解析、关键词过滤、复读黑名单和自动补齐请求。
- 排序失败时保留平级候选并显示提示；单条候选直接展示。浏览历史会话时可复制候选，填入前重新采集并核对当前会话和输入区域。
- 修复 OCR 旧消息重叠导致新消息漏读的问题。采集和识别故障显示具体原因并停止，重新开启时可再次初始化 OCR。
- 配置改为内存快照，保存成功后同步更新；文件损坏或读取失败时显示具体错误，原子保存失败时保留原文件。
- 收紧 SDK 异常处理，移除多层网络重试；保留 Gemini 明确拒绝关闭思考时的一次参数兼容请求。
- 拆分主界面、设置页和控件，清理废弃翻译、旧探针和内联自测。固定 Python 3.12 运行依赖，并统一本地与工作流构建入口。

## 本地模型配置

在 LM Studio 中加载 `d3-mini Q8_0`，将上下文长度、`Evaluation Batch Size` 和 `Physical Batch Size` 均设为 `8192`，使用全 GPU 卸载。默认物理批大小 `512` 会触发 D3 非因果注意力的底层断言。

加载配置模板可保存到：

```text
%USERPROFILE%/.lmstudio/.internal/user-concrete-model-default-config/ggml-org/vllm-d3-mini-GGUF/vllm-d3-mini-Q8_0.gguf.json
```

开启 LM Studio 本地服务后，在本程序中选择“LM Studio 本地决策”，地址填写 `http://127.0.0.1:1234`，模型填写实际加载标识，例如 `d3-mini`。回复起草在设置页单独配置。

本机中文实测：原组 12 个合成场景重复两轮，标签判定通过 `86/88`，排序通过 `24/24`；新增 8 个场景通过 `26/27`，排序通过 `8/8`。RTX 5080 上完整 29 题分析中位耗时约 `1.13 秒`，排序约 `0.21 秒`。含蓄不满的程度评分偏温和，用户可结合原话判断。
