# v0.2.0

本版本为 OpenAI Decisions 兼容版，基于原项目 v0.1.12 开发。

## 功能更新

- 新增 OpenAI Decisions 判断来源，默认使用 `gpt-6-luna`，完成意图判断、紧张度评分和候选回复排序。
- 判断密钥直接读取 `OPENAI_API_KEY`，支持进程环境变量和 Windows 用户持久环境变量，也可从设置页保存。
- 回复起草保持独立配置，所有起草来源使用 `LLM_API_KEY`。默认起草来源仍为 DeepSeek。
- 保留 OpenRouter / TypeSafe 判断来源和原有起草来源，已有来源设置继续生效。
- 设置页按当前判断来源读取密钥，切换来源时清空未保存的密钥输入。
- 重写 README，补充安装、配置、数据处理、源码运行和打包说明。
- 更新检查改为本 fork 的 Release 地址。

## 验证

- 已通过 Decisions 请求格式、响应转换、拒答处理、重试、错误脱敏、密钥隔离及引擎集成测试。
- 已使用合成对话实际调用 OpenAI Decisions，七项判断和候选排序均成功。
- 已通过 OpenAI Decisions 判断 → DeepSeek 起草 → OpenAI Decisions 排序的实际端到端调用，生成三条候选回复。
- 发布附件为 Windows 64 位构建，包含程序及运行依赖。下载后完整解压，运行 `jev-chat-windows.exe`。

源项目及第三方组件的许可证和版权说明随程序附带。
