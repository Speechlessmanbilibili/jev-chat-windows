## 本次修复

- **Anthropic SDK 兼容**：适配新版 SDK 的请求参数，移除已不支持的 `temperature` 参数，保留思考预算和输出长度设置，修复回复起草失败的问题。
- **微信输入区与 OCR**：按聊天窗口的 DPI 缩放识别边界，改进输入区分隔线判断，避免将底部控件和语音输入提示识别为聊天消息；保留聊天气泡中相同的真实文本。
- **回复对象一致性**：分析、起草和候选排序使用同一条目标消息。私聊对应最新收到的消息，群聊对应所选对象的消息；目标发生变化后先刷新分析，避免沿用旧结果。
- **SOCKS 代理依赖**：补齐 `httpx[socks]` 依赖，并将 `socksio` 纳入 Windows 发布包，修复使用 SOCKS 代理时缺少依赖的问题。
- **Gemini 思考设置兼容**：仅在模型明确拒绝关闭思考的设置时，自动使用模型默认设置重试一次；成功后按服务地址和模型记住该兼容方式，并显示中韩双语提示。其他接口错误沿用原有错误处理。

## 下载与使用

下载 `jev-chat-windows-v0.3.3.zip`，完整解压后运行 `jev-chat-windows.exe`。请保留程序旁的 `_internal` 文件夹。

OpenAI 分析使用 `OPENAI_API_KEY`，其他分析服务使用 `JEV_API_KEY`。回复起草为可选功能，所有起草服务均使用独立的 `LLM_API_KEY`。回复填入后，由用户确认发送。
